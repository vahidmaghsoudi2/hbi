## Golden rules

1. Never invent SHA or file presence.
2. Full 40-char SHA only after API/list_commits confirms it.
3. Write to `app/` only with explicit `EXECUTE_APPROVED_BY_QWEN1` + SCOPE.
4. Provenance in **commit message only** (do not forge git user.name as AI).
5. After Write: re-read file + confirm Actions on **same** head_sha.
6. End every significant report with HBI HUB — TRACE STATUS.

---

## Cycle (one stage)

```text
READ HEAD → READ SCOPE files → ANALYZE
→ (if write) wait EXECUTE_APPROVED_BY_QWEN1
→ WRITE → RE-READ → ACTIONS on same SHA → TRACE
```

### Tools (connected GitHub)

- Read: `github___list_commits`, `github___get_file_contents`, `github___get_repository_tree`
- Write: `github___create_or_update_file` (pass existing blob `sha` on update), `github___push_files`
- CI: `github___actions_list` / `github___actions_get` on workflow `test.yml`
