# HBI PROVENANCE & FOOTPRINT TRACKING PROTOCOL v1.0
Date: 2026-08-22
Authorized By: Engineer Maqsoudi (Product Owner)

## 1. Core Principle
The Product Owner (PO) does not manually author code, scripts, or documentation files. 
All technical artifacts are generated by AI Agents (Hub A or Hub B) and executed/authorized by the PO.

## 2. Commit Message Standard
Every commit MUST include the origin of the content:
Format: "[Action]: [Description] (Generated by [AI Agent], Executed by PO)"
Example: "docs: add TASK-016 canonical results (Generated by Qwen1, Executed by PO)"

## 3. WORK-REGISTRY.md Requirement
Every task entry MUST include an "Origin" field specifying which AI Agent drafted the artifact.

## 4. Accountability
- AI Agents are responsible for the technical accuracy and framework compliance of the generated content.
- The PO is responsible for reviewing, authorizing, and executing the provided scripts.
- Blaming the PO for AI-generated syntax or logic errors is strictly FORBIDDEN.

## 5. Audit Trail
All scripts provided to the PO must be logged. The PO's role is strictly "Review & Execute".
