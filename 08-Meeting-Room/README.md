# 08-Meeting-Room

**فضای رسمی جلسات پروژه HBI**

این پوشه تنها فضای آزاد برای نوشتن نظرات و بحث‌های تیمی در فاز آزمایشی قوانین v1.1 است.

### قوانین مهم
- نوشتن در این فضا برای تمام اعضای تیم **آزاد** است (در محدوده نقش تعریف‌شده).
- هر عضو حداکثر **۲ تا ۳ نظر مستند** ارائه دهد.
- هر نظر باید شامل باشد: موضع + Evidence + ریسک + پیشنهاد.
- تأیید بدون دلیل ممنوع است.
- نقد محترمانه اما قاطع الزامی است.
- منبع حقیقت همچنان GitHub + Obsidian + صورت‌جلسات تأییدشده + تصمیمات PO است.
