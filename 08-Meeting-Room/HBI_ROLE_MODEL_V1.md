## Golden rule

**Grok1 / Grok2 may Write; they do not define Truth.**

```text
Write ≠ Authority to declare correctness
```

Correctness of material changes requires:

1. Explicit scope / EXECUTE (Qwen1 and/or PO as policy requires)
2. Tests (prefer GitHub Actions on the change SHA)
3. Independent audit (ChatGPT / Qwen1) against Artifact + SHA

Auditor is **not** the GitHub executive — separation of execute vs oversee.

---

## Change cycle (material Production)

```text
Baseline TRACE
→ Change Package (exact paths)
→ EXECUTE approval
→ Write
→ Actions on SHA
→ Independent Audit
→ PO/Qwen Acceptance
```

Ceremony scales with risk; docs-only Meeting-Room commits remain lighter.
