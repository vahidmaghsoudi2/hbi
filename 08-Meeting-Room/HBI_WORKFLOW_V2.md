## 1. Principle

| Layer | Role |
|-------|------|
| **Workflow** | Engine — how work moves |
| **Law** | Guardrails — what is forbidden |
| Law must NOT replace the engine |
| Engine must NOT ignore guardrails |

If a rule stops the project for no real risk → revise the rule.

---

## 2. Hard constraint (current reality)

- Most AI members: **READ only** on GitHub.
- Grok1: Write when online (token may expire).
- **Durable path without any AI online:** PO runs **one PowerShell paste** (`agent-jobs/po-one-paste.ps1` pattern).
- Execution of tests: prefer **GitHub Actions** (tied to SHA).

---

## 3. Engine (short cycle)

```text
Qwen1 assigns TASK (Owner / Output / Done when)
        ↓
Owner READs GitHub (HEAD, files, prior Actions)
        ↓
Owner sends ONE package (template below)
        ↓
Write to GitHub (Grok1 if online, else PO one-paste)
        ↓
GitHub Actions runs on that SHA
        ↓
Owner READs result → VERIFIED or RETRY
        ↓
Short status to Qwen1 (TASK / SHA / PASS-FAIL / Run URL)
```

PO is **not** a message postman between AIs.
PO is **optional durable Write operator** when AI Write is unavailable.

---

## 4. Member package template (mandatory)

See: `agent-jobs/TEMPLATES/MEMBER_PACKAGE.txt`

One message only. No half scripts. No “paste this in PowerShell line by line”.

---

## 5. Write paths (priority)

1. **Grok1 online** → commits package to GitHub (Change Package when possible).
2. **Grok1 offline** → PO runs `agent-jobs/po-one-paste.ps1` **once** with package fields filled.
3. **Tests** → GitHub Actions (`HBI CI` / `HBI Auto Tasks`), not mandatory local pytest.

---

## 6. Guardrails (short law)

1. One Task = one Owner
2. Read before act / claim
3. Claim without SHA or Actions Run URL = REJECTED
4. NO ASSUMPTION (unknown ≠ guess)
5. Commit author = real executor (usually PO or Bridge account) — **never fake AI git identity**
6. Provenance in commit **message**: `Generated by X, Reviewed by Y, Executed by Z`
7. No token embedded in remote URL
8. Verify before Done
9. Prefer Change Package (batch related files)
10. Ceremony proportional to risk
11. Error OK; invisible error not OK
12. Rules must not freeze the project without cause

---

## 7. Done condition pattern

```text
TASK = VERIFIED only when:
  - expected files exist on GitHub at known SHA
  - if tests required: Actions conclusion success (or explicit waived by Qwen1/PO)
  - Owner confirms DONE WHEN from assignment
```
