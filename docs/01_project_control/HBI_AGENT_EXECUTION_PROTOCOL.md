# HBI — AI Execution Protocol

**Status:** Proposed; active only after merge to `master`.
**Authority:** Follow every explicit instruction from Product Owner مقصودی within applicable safety, legal, repository and accepted project constraints.

## 1. Product Owner Authority
Execute the PO's instructions end-to-end. Any AI may research, design, write, implement, test, inspect, correct, document and verify; no fixed role or assigned writer is required.

## 2. Source of Truth
Use live GitHub state, current branch/commit, accepted contracts and recorded PO decisions—not assumptions or stale summaries.

## 3. No Repeated Work
Preserve completed work. The reduction from 92 to 62 Product Intake items is complete; continue from the accepted 62-item result. Do not revive superseded inventories in active handoffs.

## 4. One Canonical Record
Update the existing authoritative artifact; avoid duplicate protocols, roadmaps, trackers or evidence ledgers.

## 5. Execute and Verify
Inspect → decide scope → act → inspect actual result → run relevant checks → record evidence → report status.

## 6. Truthful Status
Distinguish planned, done, verified, accepted, merged, blocked and unknown. Never claim an action or test succeeded without confirming evidence.

## 7. Authorization and Safe Changes
Follow PO authorization and repository controls. No protected-branch merge, destructive Git action, production-data change or protected Product A–D change without the required explicit authorization.

## 8. HBI Product Intake / G8
Preserve claim provenance; distinguish fact, manufacturer claim, evidence, inference, unknown and conflict. No invented data, keyword-only matching or numeric product scoring. G8 remains BLOCKED / NOT VERIFIED until required raw A1–A9 pilot evidence and acceptance exist.

## 9. Domain Contracts
Keep accepted domain contracts and specialized script instructions for their own scope; they do not override PO authority or this protocol's truth and safety rules.

## 10. Correct and Retire
Correct the authoritative record, update active references and retire overlapping instructions only after reconciliation. File deletion does not erase public Git history, forks, caches or copies.

## 11. Current Result and Next Action
Report only the actual result, evidence/path, unresolved blocker and next concrete action.
