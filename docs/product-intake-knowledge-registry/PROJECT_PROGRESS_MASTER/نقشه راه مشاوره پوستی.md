1. شماره هیچ فعالیتی تغییر نمی‌کند. فعالیت جدید با شماره جدید اضافه می‌شود.
2. کار انجام‌شده حذف نمی‌شود؛ وضعیت آن به انجام‌شده تغییر می‌کند و مدرک تکمیلش ثبت می‌شود.
3. اگر یک فعالیت ناقص باشد، همان شماره حفظ می‌شود و فقط بخش باقی‌مانده مشخص می‌شود.
4. PR باز تا زمان Merge و بررسی کد نهایی، انجام‌شده محسوب نمی‌شود.
5. تست Fixture و Mock به‌عنوان اثبات عملیات واقعی پذیرفته نمی‌شود.
6. تحقیقات P1 تا P7 از ابتدا تکرار نمی‌شوند؛ فقط شکاف‌های واقعی آن‌ها تکمیل می‌شود.
7. هفت Product ID موجود حفظ می‌شوند و ایجاد محصولات تکراری ممنوع است.
8. هیچ وضعیت DRAFT، PENDING، UNKNOWN یا CONFLICT صرفاً برای عبور از تست تغییر نمی‌کند.
9. هر تغییر وضعیت باید با مدرک GitHub یا خروجی معتبر اجرای واقعی همراه باشد.
10. Issue #406 مرجع اصلی تصمیم‌ها و نقشه راه باقی می‌ماند، مگر اینکه بررسی جدید ضرورت تغییر آن را ثابت کند.
