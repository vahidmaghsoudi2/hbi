## پروتکل ویرایش تا پایان این واحد کار

1. این پوشه نقطهٔ کاری واحد برای اسناد این حوزه است؛ از ساخت مرجع موازی یا کپی‌کردن کامل محتوا در سند جدید خودداری کنید.
2. پیش از هر تغییر، شاخه، PR و نسخهٔ زندهٔ فایل را بررسی کنید؛ تغییر را فقط در شاخهٔ کاری مورد تأیید ثبت کنید.
3. مرجع تجمیعی = وضعیت و ناوبری؛ Retirement Register = اعتبار و سرنوشت منابع؛ Evidence Registry = شواهد و دانش محصول؛ Execution Log = اقدام‌ها و نتیجه‌ها؛ Roadmap = جهت و ترتیب مراحل؛ PR #409 = بستهٔ بازبینی/ادغام.
4. هیچ فهرست پذیرفته‌شده‌ای را از روی نقشهٔ ساختاری یا خلاصه‌های ناقص بازسازی نکنید. مورد نامعلوم را `UNKNOWN / GAP` ثبت کنید.
5. پس از هر تغییر، لینک‌ها و وضعیت GitHub را بررسی و نتیجه را در PR ثبت کنید. تا زمانی که PR ادغام نشده، هیچ سند شاخه‌ای را روی `master` موجود فرض نکنید.
6. این محدوده صرفاً مستندات و ناوبری است؛ تغییرات بالینی، محصولی، برنامه‌ای، DB/API/Schema یا G8 خارج از دامنه‌اند.
