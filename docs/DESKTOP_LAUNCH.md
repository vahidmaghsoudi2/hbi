# راهنمای باز کردن Home از دسکتاپ (بدون دردسر روزانه)

## هدف
با **یک دابل‌کلیک** روی آیکون دسکتاپ:
1. Backend روشن شود  
2. Frontend روشن شود  
3. مرورگر روی صفحه Home باز شود  

آدرس Home: `http://127.0.0.1:5173/`  
مستندات API: `http://127.0.0.1:8000/docs`

---

## پیش‌نیاز (فقط یک‌بار روی لپ‌تاپ)

| ابزار | بررسی |
|--------|--------|
| Python 3 | در CMD بنویسید: `python --version` |
| Node.js LTS + npm | `npm --version` |
| کلون پروژه | مثلاً `E:\hbi` یا هر مسیری که `app\main.py` دارد |

اگر `npm` ندارید: از [nodejs.org](https://nodejs.org) نسخه LTS نصب کنید.

وابستگی پایتون (یک‌بار در ریشه پروژه):

```bat
cd /d مسیر\hbi
pip install -r requirements.txt
```

---

## روش پیشنهادی (دو مرحله یک‌بار، بعد فقط دسکتاپ)

### الف) ساخت میانبر دسکتاپ (یک‌بار)

1. File Explorer → پوشه پروژه `hbi`  
2. بروید به `scripts`  
3. روی `Create-Desktop-Shortcut.ps1` راست‌کلیک  
4. **Run with PowerShell**  
   - اگر ویندوز مانع شد: Properties → Unblock یا  
     `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`  
5. روی دسکتاپ میانبر **«گالری مقصودی - HBI»** ظاهر می‌شود.

### ب) هر روز

فقط **دابل‌کلیک روی همان میانبر**.

دو پنجره مشکی (Backend / Frontend) باز می‌مانند — تا وقتی کار می‌کنید **نبندید**.  
برای توقف سیستم: آن دو پنجره را ببندید.

---

## روش جایگزین بدون PowerShell

در File Explorer بروید به:

`hbi\scripts\start-hbi.bat`

دابل‌کلیک کنید.  
می‌توانید خودتان این فایل را Send to → Desktop کنید.

---

## اگر Home باز نشد

1. صبر کنید ۱۰–۱۵ ثانیه (بار اول کندتر است).  
2. دستی بروید به: http://127.0.0.1:5173/  
3. در پنجره Backend خطا را بخوانید (مثلاً پورت 8000 اشغال است).  
4. در پنجره Frontend اگر `npm` خطا داد: یک‌بار در `frontend` دستور `npm install` بزنید.  
5. مطمئن شوید آنتی‌ویروس Node/Python را مسدود نکرده.

---

## مدیریت پروژه بعد از تکمیل (چشم‌انداز)

| الان | بعداً |
|------|--------|
| میانبر + دو سرویس محلی | سرویس همیشه روشن روی PC گالری + فقط لینک Home |
| توسعه با GitHub | نسخه نصب‌شدنی اپ دسکتاپ (اختیاری) |
| `npm run dev` | `npm run build` + سرو کردن فایل ثابت |

منوها و باکس‌های Home همان رابط کاربری مرورگر هستند؛ «اپ بودن» یعنی راه‌اندازی خودکار سرویس‌ها، نه لزوماً فایل `.exe` جدا.

## فایل‌های این راهنما در مخزن

- `scripts/Create-Desktop-Shortcut.ps1` — ساخت میانبر دسکتاپ
