## ۲. سناریوهای بار (Load) — تمرکز Recommendation Engine

| ID | سناریو | شرح بار | هدف اندازه‌گیری |
|----|--------|---------|------------------|
| **R1** | Engine isolated | `ReasoningEngine.run()` با ورودی synthetic ثابت، N=50 و N=200 | CPU موتور استدلال بدون HTTP |
| **R2** | Recommendation service L0 | یک فراخوانی `generate_recommendations` (یا مسیر معادل Facade) با ۱ Case | Latency پایه مسیر توصیه |
| **R3** | Recommendation burst L1 | ۵ فراخوانی پشت‌سرهم (sequential) روی همان DB in-memory | پایداری latency / بدون نشت session |
| **R4** | Recommendation concurrent L1 | ۵ کلاینت منطقی موازی (ThreadPool روی TestClient یا حلقه service) | Error rate + p95 تحت رقابت |
| **R5** | Mixed read + recommend | قبل از recommend: list products + list evidence، سپس recommend | هزینه ORM + موتور |
| **R6** | Suite wall-clock | `pytest tests/test_reasoning/` و `pytest tests/` | سیگنال رگرسیون عملکرد تست |

**خارج از Scope Gate 7 (مگر دستور PO/Qwen1):** هزاران کاربر مجازی، k6 ابری، DB فایل Production، محصولات C/D به‌عنوان هدف توصیهٔ خودکار.

## ۴. ابزارها و اجرا در In-Memory (هم‌راستا با `conftest.py`)

### ۴.۱ اصل محیطی

- DB تست: `sqlite:///:memory:` + `StaticPool` + `PRAGMA foreign_keys=ON` (طبق fixtureهای موجود).
- **وابستگی به `data/hbi.db` ممنوع** برای اعداد رسمی Gate.
- HTTP در صورت نیاز: `fastapi.testclient.TestClient` با overrideی `get_db` (همان الگوی `client` fixture).

### ۴.۲ ابزار پیشنهادی (بدون اجبار نصب سنگین)

| ابزار | نقش |
|--------|------|
| **pytest + time.perf_counter** | R1/R6 و میکروبنچ مارک |
| **TestClient** | R2–R5 در صورت مسیر API |
| **hbi-agent-runner.ps1** | اجرای Job روی لپ‌تاپ PO و ثبت log |
| k6 / Locust | **اختیاری فاز بعد**؛ برای Gate 7 لازم نیست |

### ۴.۴ اسکript پیشنهادی (هنوز نیاز به تأیید Qwen1 قبل از افزودن به `scripts/` اگر جداگانه commit شود)

منطق پیشنهادی `scripts/perf_recommendation_baseline.py` (خلاصه — **فایل app را تغییر نمی‌دهد**):

1. ساخت engine in-memory و `Base.metadata.create_all`
2. seed حداقلی ۲ محصول VERIFIED + inventory > 0 (synthetic)
3. حلقه N بار `ReasoningEngine.run(...)` → p50/p95
4. در صورت وجود service API: حلقه TestClient روی endpoint توصیه
5. چاپ JSON: `{sha, p50, p95, throughput, errors, n}`

تا تأیید Qwen1 برای ایجاد فایل در `scripts/`، اجرا می‌تواند با pytest موجود + اندازه‌گیری دستی PO انجام شود.
