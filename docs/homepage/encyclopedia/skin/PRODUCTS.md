# محصولات دانش پوست

هر ردیف = یک باکس محصول در دانشنامه.  
برای تغییر ویژگی‌ها یا حذف از دانشنامه، همین فایل را در PR مستنداتی ویرایش کنید (یا پس از اتصال UI، از دکمهٔ ویرایش/حذف در برنامه).

وضعیت‌ها: `active` = در فهرست دانشنامه | `removed` = از دانشنامه برداشته شده (سابقه نگه داشته می‌شود).

## قالب افزودن محصول جدید

کپی کنید و پر کنید:

```markdown
## N. نام محصول

| فیلد | مقدار |
|------|--------|
| شناسه | `skin-...` |
| وضعیت | active |
| نام نمایشی | |
| ویژگی‌ها | |
| آخرین ویرایش | YYYY-MM-DD |
| یادداشت | |
```

برای **حذف از دانشنامه:** وضعیت را `removed` کنید و تاریخ را بزنید؛ ردیف را پاک نکنید تا سابقه بماند مگر مالک محصول خلاف آن را بخواهد.
