# محصولات دانش پوست

این فایل، مرجع مرکزی یافته‌های پژوهش و ویژگی‌های محصولات زیر منوی **دانشنامه → دانش پوست** است. یافته‌های پژوهشی زیر به معنی ثبت در Product Master، تأیید QA، فعال‌سازی محصول یا تأیید پزشکی نیستند.

هر ردیف نمونه‌ای که پیش‌تر ثبت شده، از پرونده‌های پژوهشی هفت محصول جداست. سه نمونهٔ اولیهٔ ANUA، Clinique و ISDIN در ابتدای فایل حفظ شده‌اند؛ هفت پروندهٔ پژوهشی نیز در بخش مستقل زیر ثبت شده‌اند.

## پرونده‌های پژوهشی هفت محصول

**وضعیت مشترک:** این‌ها پرونده‌های پژوهشی هستند، نه هفت محصول ثبت‌شده در سیستم. ادعاهای سازنده از شواهد مستقل جدا نگه داشته شده‌اند. نبود پروتکل عمومی، اثربخشی مستقل یا غلظت نامشخص باید صریح بماند. جزئیات و صف پژوهش قبلی در [دفتر پژوهش PR #411](https://github.com/vahidmaghsoudi2/hbi/pull/411) محفوظ است؛ لینک‌های منبع رسمی در هر پرونده آمده‌اند.

## قواعد شواهد برای همهٔ پرونده‌ها

1. حضور یک ماده یا شواهد عمومی همان ماده، اثربخشی محصول نهایی را ثابت نمی‌کند.
2. ادعای سازنده، شاهد مستقل، نتیجهٔ آزمایش مصرف‌کننده و مطالعهٔ بالینی باید جدا برچسب بخورند.
3. غلظت، pH، اثرگذاری درصدی، ایمنی یا روش مصرفی که در منبع معتبر نیامده، حدس زده نشود.
4. «در منابع بررسی‌شده پیدا نشد» با «وجود ندارد» یکی نیست.
5. بازار، حجم، INCI، GTIN و نسخهٔ فرمول به هر یافته متصل بمانند. نام مشابه به معنی فرمول یکسان نیست.
6. این پرونده‌ها پژوهشی‌اند و به‌تنهایی مجوز ساخت/تغییر Product Master، ProductKnowledge، QA یا فعال‌سازی نیستند.

## قالب افزودن محصول جدید به فهرست دانشنامه

```markdown
## N. نام دقیق محصول + بازار/نسخه

| فیلد | مقدار |
|------|--------|
| شناسهٔ دانشنامه | `skin-...` |
| وضعیت | active / removed |
| هویت و نسخه | |
| ترکیبات و نقش‌ها | |
| ادعاهای سازنده | |
| شواهد مستقل | |
| محدودیت‌ها و احتیاط‌ها | |
| منبع رسمی و تاریخ بررسی | |
| آخرین ویرایش | YYYY-MM-DD |
| وضعیت پژوهش | UNKNOWN / PARTIAL / CONFLICT / REVIEWED |
```

برای حذف از فهرست دانشنامه، وضعیت را `removed` کنید و ردیف را پاک نکنید تا سابقه حفظ شود. این کار به معنی حذف محصول از Product Master نیست.
