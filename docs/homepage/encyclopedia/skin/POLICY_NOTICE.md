# Policy Notice — دانش پوست / ویژگی محصولات

**Effective:** 2026-11-17  
**Binding decision:** [HBI-PO-DEC-ENCYCLOPEDIA-PRIMARY-KB-001](../../../03_decision_log/HBI-PO-DEC-ENCYCLOPEDIA-PRIMARY-KB-001.md)

## Do not use the old interpretation

The following framing is **obsolete and must not be cited**:

- دانشنامه فقط مرجع انسانی است
- دانشنامه فقط نمایشی/read-only است و در مشاوره نقشی ندارد
- کار پژوهشی دانشنامه خارج از مسیر تصمیم سیستم است

## Current binding direction

دانشنامه (شامل ویژگی محصولات پوستی و مشکلات پوستی) جهت‌گیری **بانک اصلی دانش** برای مسیر مشاوره است.

Target operating model:

```text
دانشنامه تأییدشده → Evidence → ProductKnowledge → Recommendation
```

## Notes

- این notice مجوز تغییر schema/API به‌تنهایی نیست.
- مسیر runtime فعلی هنوز از Evidence/ProductKnowledge می‌گذرد؛ تصمیم PO این است که دانشنامه باید به همان مسیر متصل شود، نه دور زده شود.
- `PRODUCTS.md` و UI دانشنامه را دیگر به‌عنوان محتوای بی‌اثر بر مشاوره تفسیر نکنید.
