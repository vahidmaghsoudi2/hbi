# دانش پوست

زیرمنوی **دانشنامه → دانش پوست** در هوم‌پیج.

## نقش این پوشه

ثبت فهرست محصولات دانشی پوست، ویژگی‌ها، و تصمیم‌های مربوط به **همین زیرمنو** — تا سال‌های بعد گم نشوند.

| فایل | محتوا |
|------|--------|
| [PRODUCTS.md](./PRODUCTS.md) | فهرست محصولات + ویژگی‌ها + ویرایش/حذف از دانشنامه |
| [DECISIONS.md](./DECISIONS.md) | تصمیم‌های مالک محصول دربارهٔ این زیرمنو |

## مرزها

- این فهرست **دانشنامه‌ای** است؛ جایگزین اجباری Product Master / Intake نیست مگر صریحاً تصمیم گرفته شود.
- بانک مشکلات پوست (P01–P61) در `docs/product-intake-knowledge-registry/` است و اینجا **تکرار نمی‌شود**.
- منوی دانشنامه و خودِ زیرمنوی دانش پوست حذف‌شدنی نیستند.

## مسیر در UI برنامه

منوی اصلی → دانشنامه → دانش پوست
