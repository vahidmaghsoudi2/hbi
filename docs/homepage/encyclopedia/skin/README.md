# دانش پوست

مسیر فعال هوم‌پیج: **دانشنامه → دانش پوست**. این صفحهٔ واسط دو مقصد مستقل دارد:

1. **ویژگی محصولات پوستی:** نمای read-only موجود و [دفتر پژوهش هفت محصول P1–P7](./PRODUCTS.md).
2. **مشکلات پوستی:** پیوند به [Workspace Index بانک مرجع P01–P61](../../../product-intake-knowledge-registry/SKIN_PROBLEM_BANK_WORKSPACE_INDEX.md). این مرجع، فهرست و رکوردهای موجود را مدیریت می‌کند؛ این پوشه هیچ نسخه‌ای از آن‌ها نگهداری نمی‌کند.

این دو مسیر از نظر داده مستقل‌اند. رابطهٔ محصول/مشکل فقط از ProductProblemLink موجود قابل ارجاع است؛ `known_use_cases` یا `skin_goals` جایگزین آن نیستند. در این تغییر صرفاً ناوبری هوم‌پیج اصلاح می‌شود؛ هیچ بانک، رکورد، شناسه، محتوا یا رابطهٔ تازه‌ای ساخته نمی‌شود.

## نقش این پوشه

مرجع مرکزی برای پیدا کردن یافته‌های پژوهش محصولات پوستی، ویژگی‌ها، محدودیت شواهد، تفاوت نسخه‌های بازار، تصمیم‌ها و وضعیت کار. هر یافته باید به پروندهٔ محصول مربوط اضافه شود و منبع قابل پیگیری داشته باشد.

| فایل | محتوا |
|------|--------|
| [PRODUCTS.md](./PRODUCTS.md) | پرونده‌های پژوهشی هفت محصول، ترکیبات/نقش‌ها، ادعاها، قدرت شواهد، محدودیت‌ها و منابع؛ همچنین سه نام نمونهٔ اولیه |
| [DECISIONS.md](./DECISIONS.md) | تصمیم‌های مربوط به دانش پوست، وضعیت Gate 1 و پیوند مستقیم به ممیزی‌ها و نتایج ثبت‌شده |
| [PROBLEM_BANK_S04_S10_STATUS.md](./PROBLEM_BANK_S04_S10_STATUS.md) | خلاصهٔ نتایج پوشش S04–S10، وضعیت بازبینی و پیوند به مرجع اصلی بانک مشکلات؛ بدون ایجاد فهرست موازی |

## قالب‌های آماده و هماهنگی برای تست

- **مرجع قالب‌های ورود محصول V1:** [SKIN_INTAKE_TEMPLATE_FORMS_V1.md](https://github.com/vahidmaghsoudi2/hbi/blob/master/docs/homepage/product-management/SKIN_INTAKE_TEMPLATE_FORMS_V1.md)
- V1 شامل ۹ قالب مصوب است؛ آبرسان و مرطوب‌کننده یک قالب مشترک `HYDRATING_MOISTURIZER` دارند و ضدآفتاب قالب اختصاصی `SUNSCREEN` دارد.
- این مرجع زیر «مدیریت محصولات → ورود و ویرایش محصول» قرار می‌گیرد؛ این پوشهٔ دانشنامه محل دسترسی، پژوهش و هماهنگی است، نه منبع دوم برای ثبت عملیاتی.
- تیم محصول، هویت دقیق نسخه، بازار، منبع، ترکیبات اعلام‌شده، روش مصرف و ادعاهای سازنده را با ارجاع ثبت می‌کند.
- تیم رصد مشکلات پوستی، فقط ارتباط‌های احتمالی و پشتوانهٔ شواهد را بررسی می‌کند. اهداف پوستی در V1 متن نامزد هستند؛ هیچ پیوند خودکار یا شناسه‌گذاری خودکار P01–P61 مجاز نیست.
- مقادیر نامعلوم مانند بازار، حجم، رنگی/بی‌رنگ و ترکیبات کامل باید نامعلوم بمانند؛ پیش‌فرض‌های `IR`، `50 ml` یا `clear` را به FACT تبدیل نکنید.
- خروجی تست این مرحله، بررسی فرم و کیفیت پیش‌نویس است؛ نه ثبت محصول، تأیید QA، فعال‌سازی یا مجوز تغییر API/schema/DB.

### چک‌لیست آمادگی تست قالب‌ها

- [ ] مسیر «مدیریت محصولات → ورود و ویرایش محصول» و لینک مرجع قالب برای تیم قابل پیدا کردن است.
- [ ] انتخاب قالب، یکی از ۹ گزینهٔ V1 را نشان می‌دهد؛ آبرسان/مرطوب‌کننده دو گزینهٔ جدا نیستند.
- [ ] باکس‌های مشترک و باکس‌های اختصاصی قالب انتخاب‌شده از هم قابل تشخیص‌اند.
- [ ] منبع و نوع ادعا برای اطلاعات منبع‌محور قابل ثبت یا علامت‌گذاری به‌عنوان نامعلوم است.
- [ ] تکمیل هوشمند هیچ FACT تأییدنشده‌ای برای `IR`، `50 ml`، `clear` یا درصد اثربخشی تولید نمی‌کند.
- [ ] ادعای اثربخشی پیشنهادی در حالت پیش‌نویس/ادعای سازنده باقی می‌ماند و خودکار VERIFIED نمی‌شود.
- [ ] هدف پوستی فقط متن است و هیچ شناسهٔ P01–P61 به‌صورت خودکار تخصیص نمی‌یابد.
- [ ] تیم رصد می‌تواند شواهد، محدودیت‌ها و تعارض‌ها را بررسی کند بدون اینکه بانک مشکلات را کپی یا تغییر دهد.
- [ ] DuplicateCheck و مسیر Draft/QA موجود حفظ می‌شوند.
- [ ] نتیجهٔ هر مورد تست با PASS / FAIL / BLOCKED و شاهد قابل بازتولید ثبت می‌شود.

**مرز وضعیت:** این چک‌لیست معیار آماده‌سازی و اجرای تست است؛ تا زمانی که تست واقعی اجرا نشده، هیچ موردی را PASS اعلام نکنید. اجرای تغییر کد، API، DB یا ثبت محصول همچنان تابع مجوز صریح در Issue #406 است.

## منابع و مرزها

- مرجع تصمیم‌ها و مجوزهای سراسری: [Issue #406](https://github.com/vahidmaghsoudi2/hbi/issues/406).
- دفتر پژوهش و سابقهٔ فنی: [PR #411](https://github.com/vahidmaghsoudi2/hbi/pull/411). یافته‌های قابل استفاده باید از همین هاب دانشنامه نیز قابل پیدا کردن باشند.
- پیشنهاد و بررسی ساختار هاب دانشنامه: [PR #446](https://github.com/vahidmaghsoudi2/hbi/pull/446).
- بانک مشکلات پوست (P01–P61) در `docs/product-intake-knowledge-registry/` باقی می‌ماند و اینجا کپی نمی‌شود.
- پرونده‌های این پوشه پژوهشی‌اند؛ جایگزین Product Master / Intake نیستند و به‌تنهایی مجوز ثبت محصول، تأیید QA، فعال‌سازی یا تغییر کد/API/schema/DB نیستند.
- ادعاهای سازنده، شواهد مستقل، داده‌های مادهٔ منفرد و شواهد محصول نهایی با هم یکی فرض نشوند. UNKNOWN و CONFLICT آشکار بمانند.
- نسخهٔ بازار، حجم، INCI و GTIN باید به یافتهٔ مربوط وصل باشند؛ نام مشابه به معنی فرمول یکسان نیست.

## مسیر در UI برنامه

منوی اصلی → دانشنامه → دانش پوست → (ویژگی محصولات پوستی | مشکلات پوستی)

**محدودیت وضعیت فعلی:** پیوند «مشکلات پوستی» به Workspace Index می‌رود. نمایش زندهٔ ProductProblemLink در هر دو صفحه هنوز در UI پیاده‌سازی نشده و در دامنهٔ این اصلاح ناوبری نیست.
