# دانش پوست

زیرمنوی **دانشنامه → دانش پوست** در هوم‌پیج.

## نقش این پوشه

مرجع مرکزی برای پیدا کردن یافته‌های پژوهش محصولات پوستی، ویژگی‌ها، محدودیت شواهد، تفاوت نسخه‌های بازار، تصمیم‌ها و وضعیت کار. هر یافته باید به پروندهٔ محصول مربوط اضافه شود و منبع قابل پیگیری داشته باشد.

| فایل | محتوا |
|------|--------|
| [PRODUCTS.md](./PRODUCTS.md) | پرونده‌های پژوهشی هفت محصول، ترکیبات/نقش‌ها، ادعاها، قدرت شواهد، محدودیت‌ها و منابع؛ همچنین سه نام نمونهٔ اولیه |
| [DECISIONS.md](./DECISIONS.md) | تصمیم‌های مربوط به دانش پوست، وضعیت Gate 1 و پیوند مستقیم به ممیزی‌ها و نتایج ثبت‌شده |

## منابع و مرزها

- مرجع تصمیم‌ها و مجوزهای سراسری: [Issue #406](https://github.com/vahidmaghsoudi2/hbi/issues/406).
- دفتر پژوهش و سابقهٔ فنی: [PR #411](https://github.com/vahidmaghsoudi2/hbi/pull/411). یافته‌های قابل استفاده باید از همین هاب دانشنامه نیز قابل پیدا کردن باشند.
- پیشنهاد و بررسی ساختار هاب دانشنامه: [PR #446](https://github.com/vahidmaghsoudi2/hbi/pull/446).
- بانک مشکلات پوست (P01–P61) در `docs/product-intake-knowledge-registry/` باقی می‌ماند و اینجا کپی نمی‌شود.
- پرونده‌های این پوشه پژوهشی‌اند؛ جایگزین Product Master / Intake نیستند و به‌تنهایی مجوز ثبت محصول، تأیید QA، فعال‌سازی یا تغییر کد/API/schema/DB نیستند.
- ادعاهای سازنده، شواهد مستقل، داده‌های مادهٔ منفرد و شواهد محصول نهایی با هم یکی فرض نشوند. UNKNOWN و CONFLICT آشکار بمانند.
- نسخهٔ بازار، حجم، INCI و GTIN باید به یافتهٔ مربوط وصل باشند؛ نام مشابه به معنی فرمول یکسان نیست.

## مسیر در UI برنامه

منوی اصلی → دانشنامه → دانش پوست
