# دانش پوست

این مسیر، بخش دانش پوست در دانشنامهٔ HBI است و از ساختار دانشنامهٔ اصلی پیروی می‌کند. دانشنامه مرجع انسانی اصلی و زندهٔ دانش تأییدشده است؛ این پوشه صرفاً ویترین یا نسخهٔ نمایشی ProductKnowledge نیست.

## دو مقصد مستقل

1. **ویژگی محصولات پوستی:** مرجع انسانی و قابل ویرایش دانش محصول و پرونده‌های پژوهشی در [PRODUCTS.md](./PRODUCTS.md). محتوای تأییدشده و پیش‌نویس‌های پژوهشی باید با وضعیت جدا و آشکار نگهداری شوند.
2. **مشکلات پوستی:** پیوند به [Workspace Index بانک مرجع P01–P61](../../../product-intake-knowledge-registry/SKIN_PROBLEM_BANK_WORKSPACE_INDEX.md). این مرجع، فهرست و رکوردهای موجود را مدیریت می‌کند؛ این پوشه هیچ نسخه‌ای از آن‌ها نگهداری نمی‌کند.

این دو مسیر از نظر داده مستقل‌اند. رابطهٔ محصول/مشکل فقط از ProductProblemLink موجود قابل ارجاع است؛ `known_use_cases` یا `skin_goals` جایگزین آن نیستند.

## مسیر دانش محصول

`Approved Encyclopedia → Evidence / Source Traceability → ProductKnowledge → Consultation`

- محتوای تأییدشدهٔ محصول در دانشنامه نگهداری می‌شود و باید به منبع اولیه، از جمله صفحهٔ رسمی سازنده و متن بسته‌بندی، قابل ردیابی باشد.
- منبع اولیه با خلاصهٔ دانشنامه جایگزین نمی‌شود.
- Evidence و Source Traceability پشتیبان منشأ و بازبینی‌اند، نه بانک موازی یا تأییدیهٔ جداگانه.
- ProductKnowledge تنها بانک عملیاتی runtime برای مصرف HBI است.
- تأیید PO پذیرش محتوای محصول را کامل می‌کند؛ پس از آن Gate محتوایی تکراری اضافه نمی‌شود.

## دامنهٔ Skin Consultation V1

- دقیقاً هفت Product ID موجود؛ محصول جدیدی از روی نام یا برند ساخته نمی‌شود.
- دامنهٔ COSRX فقط **The 6 Peptide Skin Booster Serum** است.
- منابع V1 به افشاگری رسمی سازنده و اطلاعات چاپ‌شده روی بسته محدود است. ادعای سازنده همواره ادعای سازنده باقی می‌ماند.
- بازار، فرمول، حجم و INCI صفحهٔ وب به بستهٔ فیزیکی منتقل نمی‌شود مگر تطبیق آن مستند باشد.
- UNKNOWN و CONFLICT حفظ می‌شوند؛ Anua cleanup یا بازتأیید هویت محصولات انجام نمی‌شود مگر نقص runtime مشخص و تازه‌ای مشاهده شود.
- بررسی مستقل علمی، مطالعات بیرونی و تکمیل جامع علمی خارج از دامنهٔ V1 است.

## قالب‌ها و هماهنگی ورود محصول

- **مرجع قالب‌های ورود محصول V1:** [SKIN_INTAKE_TEMPLATE_FORMS_V1.md](https://github.com/vahidmaghsoudi2/hbi/blob/master/docs/homepage/product-management/SKIN_INTAKE_TEMPLATE_FORMS_V1.md)
- V1 شامل ۹ قالب مصوب است؛ آبرسان و مرطوب‌کننده یک قالب مشترک `HYDRATING_MOISTURIZER` دارند و ضدآفتاب قالب اختصاصی `SUNSCREEN` دارد.
- این مرجع زیر «مدیریت محصولات → ورود و ویرایش محصول» قرار می‌گیرد؛ دانشنامه مرجع انسانی دانش است و ProductKnowledge بانک عملیاتی باقی می‌ماند.
- منبع و نوع گزاره برای اطلاعات منبع‌محور باید ثبت یا در صورت نبود منبع UNKNOWN بماند.
- هیچ `FACT` تأییدنشده‌ای برای بازار، حجم، رنگی/بی‌رنگ یا درصد اثربخشی ساخته نشود.
- هدف پوستی فقط متن نامزد است؛ هیچ شناسهٔ P01–P61 به‌صورت خودکار تخصیص نمی‌یابد.

## مرز وضعیت فعلی

- این تغییر مستنداتی، به‌تنهایی UI، API، DB، Product Master، ProductKnowledge، QA، چرخهٔ عمر یا دادهٔ مشتری را تغییر نمی‌دهد.
- پیوند «مشکلات پوستی» به Workspace Index می‌رود. نمایش زندهٔ ProductProblemLink در هر دو صفحه هنوز در UI پیاده‌سازی نشده و در دامنهٔ این اصلاح مستنداتی نیست.
- پرونده‌های پژوهشی تا زمان تأیید PO، پیش‌نویس‌اند و نباید به‌عنوان دانش پذیرفته‌شده یا مجوز Recommendation تلقی شوند.
