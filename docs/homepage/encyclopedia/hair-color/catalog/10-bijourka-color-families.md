# فعالیت ۱۰ — تثبیت خانواده‌های رنگی در کاتالوگ

## ۱. هدف و حد اجرا
این فعالیت خانواده/سری رنگی را در دادهٔ کاتالوگ با نام خام خود تثبیت می‌کند و یک دسته‌بندی فرعی برای جست‌وجو/مرتب‌سازی پیشنهاد می‌دهد. طبقه‌بندی فرعی **پیشنهادی و تصویب‌نشده** است؛ برچسب‌های کاتالوگ صرفاً هویت/نام‌گذاری‌اند و دلیل شیمی، پیگمنت، خنثی‌سازی، لیفت، عملکرد یا نتیجه نیستند.

## ۲. منبع و اصل هویت
- منبع: snapshot ثبت‌شدهٔ ۸۸ رکوردی در `raeaka_bijourka_catalog.csv`.
- خانوادهٔ کاتالوگی در این فعالیت برابر نام خام ستون «سری محصول» است.
- کلید هویت همچنان `(brand, series_name_raw, shade_code_raw)` است.
- نام رنگ و شمارهٔ رنگ برای تعیین خانواده استفاده نمی‌شوند.
- هیچ نام/کد مشابهی برای برند دیگر نگاشت نمی‌شود.

## ۳. ۱۹ برچسب خانوادهٔ کاتالوگی
نام‌ها عیناً حفظ می‌شوند: طبیعی، طبیعی اکسترا، خاکستری، دودی، زیتونی، طلایی، بژ، نسکافه ای، آلبالویی، شکلاتی، عسلی، فندقی، شرابی، قرمز، عروسکی، بیسکویتی، کاپوچینو، ترکیبی، واریاسیون.

## ۴. دسته‌بندی فرعی پیشنهادی (برای ناوبری؛ PO approval pending)
| گروه پیشنهادی | سری‌های خام عضو |
|---|---|
| natural | طبیعی؛ طبیعی اکسترا |
| cool_named | خاکستری؛ دودی |
| green_named | زیتونی |
| gold_named | طلایی؛ عسلی |
| beige_named | بژ |
| brown_named | نسکافه ای؛ شکلاتی؛ فندقی؛ بیسکویتی؛ کاپوچینو |
| red_named | آلبالویی؛ شرابی؛ قرمز |
| creative_named | عروسکی؛ ترکیبی |
| special_named | واریاسیون |

این دسته‌بندی فقط برای navigation/filtering است. حتی نام گروه‌هایی مانند cool_named یا gold_named به معنای تأیید فنی رفتار، تناژ، خنثی‌سازی یا اثر نیست. در صورت مخالفت/اصلاح PO، mapping قابل تغییر است؛ تا تصویب، وضعیت آن provisional است.

## ۵. قرارداد اجرایی
ماژول `app/domain/hair_catalog_families.py`:
- فقط نام خام سری دقیق را قبول می‌کند؛ بدون trim، تبدیل حروف، alias یا fuzzy match.
- `catalog_family_label` عین نام خام سری را برمی‌گرداند.
- `editorial_group` گروه فرعی پیشنهادی را برمی‌گرداند و `editorial_group_status=provisional` دارد.
- نام ناشناخته یا تغییر یافته را `None` برمی‌گرداند (fail-closed).
- از کد رنگ، نام رنگ یا کدهای فعالیت ۹ برای تعیین خانواده استفاده نمی‌کند.

## ۶. آزمون‌های ثبت‌شده
- مجموعه و ترتیب ۱۹ نام خام دقیق.
- حفظ نام خام به‌عنوان family label.
- provisional بودن گروه‌های فرعی.
- رد نام ناشناخته، whitespace تغییر یافته و ورودی غیررشته‌ای.
- جدایی family label از گروه فرعی.

## ۷. مرز ادعا و موارد خارج از فعالیت
این فعالیت تعیین نمی‌کند: undertone، pigment، شدت/اشباع، سطح، لیفت، ترکیب شیمیایی، اکسیدان، نسبت ترکیب، زمان مکث، خنثی‌سازی، سازگاری، ایمنی یا نتیجه روی مو. CSV و manifest تغییر نکرده‌اند. خانوادهٔ کاتالوگی از دادهٔ مو یا هدف مشتری قابل استنتاج نیست.

## ۸. وضعیت
- ۱۹ نام خام سری به‌عنوان خانوادهٔ کاتالوگی تثبیت شدند.
- گروه‌بندی فرعی به‌صورت provisional در کد ثبت شد؛ تأیید PO برای آن ادعا نمی‌شود.
- کد و آزمون‌ها ثبت شدند؛ اجرای آزمون/CI در این PR ادعا نمی‌شود.
- PR Draft و بدون Merge باقی می‌ماند.

## ۹. گام بعدی
**فعالیت ۱۱ — تثبیت قواعد اختصاصی مصوب مالک پروژه.** در فعالیت بعدی، قواعد پراکندهٔ مالک پروژه تجمیع و منشأ/حدود هر قاعده جدا می‌شود؛ خانواده‌بندی پیشنهادی حاضر نیز در صورت نیاز در همان چارچوب بررسی می‌شود.
