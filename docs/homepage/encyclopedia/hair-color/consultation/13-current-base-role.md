# فعالیت ۱۳ — تعیین نقش پایهٔ فعلی مو در انتخاب رنگ

## هدف
پایه/عمق فعلی یک توصیف از وضعیت موجود است که در ارزیابی هدف و تفاوت نواحی نقش ورودی دارد؛ به‌تنهایی انتخاب رنگ، رفله، پیگمنت، لیفت، فرمول یا نتیجه را تعیین نمی‌کند.

## مقیاس توصیفی مرجع (تقریبی)
| سطح | برچسب عمومی توصیفی |
|---:|---|
| ۱ | مشکی |
| ۲ | قهوه‌ای بسیار تیره |
| ۳ | قهوه‌ای تیره |
| ۴ | قهوه‌ای متوسط |
| ۵ | قهوه‌ای روشن |
| ۶ | بلوند تیره |
| ۷ | بلوند متوسط |
| ۸ | بلوند روشن |
| ۹ | بلوند بسیار روشن |
| ۱۰ | بلوند بسیار روشن‌ترین |

این scale یک مرجع توصیفی تقریبی است؛ ممکن است نام‌گذاری در برندها/منابع تفاوت داشته باشد. برچسب سطح به معنی تعیین undertone، پیگمنت زمینه، درصد روشن‌شدن، سابقهٔ رنگ یا امکان‌پذیری هدف نیست.

## قواعد ثبت
- هر ناحیه جداگانه ثبت شود (ریشه، میانه، انتها یا ناحیهٔ خاص).
- level می‌تواند ۱ تا ۱۰ یا نامعلوم باشد؛ نامعلوم با حدس پر نمی‌شود.
- منبع داده: مشاهدهٔ حرفه‌ای، اظهار مشتری، سند، تصویر تنها یا نامعلوم.
- تصویر تنها، حتی اگر تخمین سطح ثبت شده باشد، وضعیت uncertain_review دارد؛ تأیید مشاهده‌ای لازم است وقتی تصمیم به آن وابسته است.
- confidence پایین/نامعلوم باعث وضعیت uncertain_review می‌شود.
- توصیف خام مشتری/متخصص جدا از level عددی نگهداری می‌شود.
- سطح فعلی، رنگ مصنوعی/طبیعی بودن، سابقهٔ شیمیایی، پیگمنت یا ساختار مو را اثبات نمی‌کند.

## نقش در تصمیم
پایهٔ فعلی فقط یک ورودی توصیفی برای بررسی هدف و ارزیابی نواحی است. این سند هیچ rule انتخاب رنگ یا فرمول ندارد. هر استنتاج دربارهٔ پیگمنت زمینه، تناژ، لیفت یا رفتار رنگ نیازمند دانش/شواهد جداگانه در فعالیت‌های مرتبط است. تفاوت نواحی و منبع/اعتماد هر توصیف باید حفظ شود.

## قرارداد نرم‌افزاری
ماژول app/domain/hair_color_current_base.py سطح ۱ تا ۱۰ را به برچسب‌های تقریبی می‌نگارد، ورودی نامعتبر را رد می‌کند و وضعیت uncertain_review را برای تصویر-only، unknown، سطح نامعلوم یا اعتماد پایین/نامعلوم ثبت می‌کند. این ماژول خروجی رنگ یا توصیه تولید نمی‌کند.

## آزمون‌ها
- سطح‌های ۱ تا ۱۰ و حدهای label؛
- ثبت توصیف observed به‌صورت descriptive_only؛
- image-only به‌عنوان uncertain؛
- سطح نامعلوم بدون حدس؛
- رد سطح نامعتبر/boolean؛
- رد region یا source نامعتبر؛
- عدم قطعیت confidence نامعلوم.

اجرای test/CI هنوز تأیید نشده است.
