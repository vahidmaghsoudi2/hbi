# دانشنامه — حوزه‌های دانشی غیرپوستی و سوابق

**جایگاه در HBI:** دانشنامه یک مسیر سازمان‌دهی و دسترسی به محتواست؛ بانک موازی ProductKnowledge نیست. معماری معتبر HBI در [تصمیم سه‌بخشی HBI](../../03_decision_log/HBI-PO-DEC-THREE-PART-001.md) تعریف شده است.

**تصمیم فعلی:** دانش پوست از نظر ساختار هدف به محیط یکپارچه «مدیریت محصولات» منتقل می‌شود. شش حوزه غیرپوستی دانشنامه فعلاً حفظ می‌شوند و محتوای آن‌ها در این مرحله تغییر نمی‌کند.

**مسئله باز ناوبری:** جایگاه دقیق این شش حوزه در UI پس از یکپارچه‌سازی دانش پوست هنوز تعیین نشده است. تا تصمیم صریح بعدی، هیچ‌یک از مسیرهای دسترسی فعلی حذف یا جابه‌جا نشود. این سند حذف منوی اصلی «دانشنامه» را تصویب نمی‌کند.

## ارتباط با مدیریت محصولات و ProductKnowledge

- محیط هدف مدیریت محصولات شامل «کالا و ویژگی محصول» و «مشکلات پوستی» است.
- پرونده هر محصول مرجع ویژگی‌های همان محصول است؛ ویژگی‌ها در بانک مستقل دیگری تکثیر نمی‌شوند.
- دانش مشکلات پوستی با محصولات و ویژگی‌های مرتبط، رابطه ساختاریافته دارد؛ بانک مرجع مشکلات در محل تخصصی فعلی خود حفظ می‌شود و کپی نمی‌شود.
- ProductKnowledge مرجع واحد اطلاعات معتبر محصولات است. دانشنامه یا صفحه‌های نمایشی، بانک یا فرایند تأیید موازی ایجاد نمی‌کنند.
- تأیید Product Owner پایان پذیرش اطلاعات محصول است؛ Gate QA جداگانه پس از آن وجود ندارد.
