## ساختار داخلی دانش پوست

مسیر ناوبری مصوب و جاری در هوم‌پیج:

`دانشنامه → دانش پوست → (ویژگی محصولات پوستی | مشکلات پوستی)`

- **ویژگی محصولات پوستی:** نمای read-only موجود و [فهرست پژوهش P1–P7](./skin/PRODUCTS.md).
- **مشکلات پوستی:** پیوند به [Workspace Index بانک مرجع P01–P61](../../product-intake-knowledge-registry/SKIN_PROBLEM_BANK_WORKSPACE_INDEX.md).
- این دو مقصد مستقل‌اند؛ هیچ‌یک داده‌های دیگری را کپی نمی‌کند. ارتباط مستند محصول/مشکل از ProductProblemLink موجود پیروی می‌کند. نمایش زندهٔ روابط در UI بخشی از این تغییر ناوبری نیست.
- این ساختار، توصیف قدیمیِ قرارگرفتن دو مقصد به‌صورت کارت‌های هم‌سطح با همهٔ زیرمنوهای دانشنامه را supersede می‌کند؛ PR #441 و #471 به‌عنوان تاریخچهٔ پیاده‌سازی حفظ می‌شوند.

## قواعد ثبت (الزامی)

1. هر تصمیم یا تغییر مربوط به یک زیرمنو **فقط در پوشهٔ همان زیرمنو** نوشته شود.
2. زیرمنوهای اصلی دانشنامه **حذف نمی‌شوند**؛ فقط محتوای داخل آن‌ها ویرایش می‌شود.
3. محصول داخل دانش پوست در `skin/PRODUCTS.md` ثبت شود (افزودن / ویرایش / حذف از فهرست دانشنامه).
4. ادعای پزشکی یا تکمیل بانک محصول بدون شاهد رسمی ثبت نشود.
5. Issue یا PR موازی برای همین ساختار نسازید مگر مالک محصول بخواهد.
