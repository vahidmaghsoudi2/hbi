## V1 objective

V1 is not a “best perfume engine.”

V1 aims only to establish whether HBI can support a small, evidence-aware, human-assisted and traceable fragrance-candidate flow.

## V1 candidate capability

```text
Product Identity + Product Availability + Attributable Product Information
+ Customer Stated Preference / Avoidance + Current Usage Context
+ Unknown / Conflict Visibility + Eligibility Boundary
+ Human-assisted Candidate Explanation + Decision Trace
```

## V1 non-goals

```text
Similarity; Numeric scoring; Automatic ranking; Automatic recommendation;
Automatic learning; Personal taste prediction; Derived profile engine;
Performance normalization; Cross-market equivalence; Advanced weather logic;
Advanced allergen model; New Product Master; New Evidence Engine;
New ProductKnowledge Engine; New Lifecycle Engine
```

## V1 decision rules

```text
Unknown must remain Unknown.
Conflict must remain visible.
Marketing gender must not become a hard filter.
Season and occasion must not become automatic hard filters.
Concentration must not become a performance guarantee.
Customer purchase must not be treated as customer satisfaction.
Customer discomfort must not become medical diagnosis.
```

## V1 Definition of Done candidate (not approved acceptance contract)

A future V1 should only be considered ready for review if:

- a real product identity is traceable;
- operational availability is traceable;
- at least one attributable product-information item or explicit UNKNOWN exists;
- a customer preference or avoidance can be captured/retrieved;
- current context can be represented at minimum level;
- a human operator can review a candidate explanation;
- unknowns and conflicts are visible;
- decision trace is available;
- no scoring, similarity, automatic ranking or automatic learning is present.
