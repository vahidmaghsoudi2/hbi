**Status:** ACTIVE — APPROVED BY PO  
**Date:** 2026-08-28  
**Approved by:** مهندس مقصودی (Product Owner)  
**Replaces:** All previous rigid "Role Descriptions"

---

## Core Principle

> **«You are not responsible for a file; you are responsible for a RESULT.»**

---

## What We ELIMINATE

- "You are only Backend."  
- "This part is not my job."  
- Handing off incomplete work without a clear owner.  
- Rigid job descriptions that block progress.

---

## What We REPLACE With

**MISSION OWNERSHIP — END TO END**

- ONE Owner per mission
- Owner carries mission through ALL phases: Inspect → Change → Test → Deliver → Report
- No "this is not my role" boundaries

---

## Five Non-Negotiable Rules

1. Source of Truth = Real Repository
2. No Invented State / No Invented Data
3. Frozen Artifacts Must Not Be Modified (scoring.py, seed_products.json, Products A-D)
4. Work Must Be Delivered With Evidence (commits, tests, outputs)
5. Owner Removes Obstacles Themselves

---

## Team Model

PRODUCT OWNER (مهندس مقصودی) → MISSION → ONE OWNER → Inspect/Change/Test → FINAL RESULT → REPORT
