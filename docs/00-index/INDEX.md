# HBI — فهرست مرکزی مراجع رسمی

**وضعیت:** نقشهٔ ناوبری (2026-10-23). این فایل **مرجع تصمیم نیست**؛ فقط نشان می‌دهد هر حوزه کجا ثبت می‌شود و کدام منبع اعتبار دارد.

**قواعد ثابت**

1. این INDEX جایگزین Issue/PR/پوشهٔ مرجع نمی‌شود؛ فقط لینک، نقش و وضعیت می‌دهد.
2. وضعیت تأییدنشده را نهایی یا فعال معرفی نکنید؛ صریحاً «در انتظار بررسی / باز / PARTIAL» بماند.
3. تصمیم و مجوز → Issue رسمی همان حوزه. شواهد و کار جاری → PR همان حوزه. مستندات ماندگار → پوشهٔ ثابت در `docs/`.
4. چت محل هماهنگی است، نه مرجع نهایی.
5. Problem Space از مسیر محصول/هوم‌پیج جدا نگه داشته شود مگر تصمیم صریح PO.

## چیزی که این فایل انجام نمی‌دهد

- کپی تاریخچهٔ کامنت‌ها یا بدنهٔ Issueها
- اعلام تکمیل بانک محصول، Gate 0 بسته، یا G8 پاس
- مجوز تغییر کد، schema، API، UI یا پایگاه داده
- ساخت پوشه‌های خالی برای خرید/فروش/… تا وقتی محتوای واقعی لازم شود

## نگهداری

وقتی مرجع رسمی جدیدی برای یک حوزه تثبیت شد، **یک ردیف** به جدول بالا اضافه یا به‌روز کنید. از ایجاد INDEX موازی خودداری کنید.
