# نقشه اتصال واحد پروفایل مشتری به سایر واحدها — v1

واحد پروفایل **پویا** است: هم تغذیه می‌کند، هم تغذیه می‌شود.

## جریان داده

```
                    ┌─────────────────────┐
                    │  Customer Profile   │
                    │  (این واحد)         │
                    └──────────┬──────────┘
           ┌───────────────────┼───────────────────┐
           ▼                   ▼                   ▼
     ┌──────────┐        ┌──────────┐        ┌──────────┐
     │  Case    │        │ Recommend│        │  Sale    │
     │ (مشاوره) │◄──────►│  Engine  │◄──────►│ (فروش)   │
     └──────────┘        └──────────┘        └──────────┘
           │                   │                   │
           └───────────────────┼───────────────────┘
                               ▼
                    ┌─────────────────────┐
                    │ Follow-up / Outcome │
                    │ Timeline / Audit    │
                    └─────────────────────┘
```

## قرارداد اتصال (نسخه ۱)

| واحد مقصد | چه می‌گیرد از پروفایل | چه برمی‌گرداند به پروفایل |
|-----------|------------------------|----------------------------|
| **Case** | customer_id، هدف/نگرانی جلسه | case_id، identified_needs |
| **Recommendation** | profile تازه + Visit answers (نه حدس) | recommendation_id، eligibility، دلیل |
| **Sale / POS fallback** | customer_id | purchase event → Timeline + Outcome |
| **Follow-up** | contact preference، Factهای مرتبط | رضایت، واکنش، نیاز پیگیری |
| **Evidence / Product** | — (فقط خواندن قوانین Safety) | محدودیت توصیه |
| **Auth** | customer_id برای ownership | — |

## قوانین پویایی
1. هر خرید/عدم‌خرید → رویداد Timeline (نه بازنویسی خاموش Fact).
2. هر Outcome منفی Safety → در مراجعات بعدی قابل مشاهده.
3. Recommendation فقط از Fact **تأییدشده و تازه** یا پاسخ **همین Visit** استفاده کند.
4. ویرایش پروفایل توسط مشتری/فروشنده با Audit ثبت شود.
5. مدل فعلی `Customer` (رشته‌ای) تا Phase 2 حفظ می‌شود؛ مهاجرت تدریجی است.

## عدم شکستن Pilot
مسیر فعلی `Customer → Case → Auth → Recommendation` تا Gate 4 بدون تغییر اجباری باقی می‌ماند؛ اتصال جدید به‌صورت additive است.
