## Acquisition Owner Boundary

GPT-1 and GPT-2 must not manufacture, simulate, or silently substitute for a missing real-world source.

Until an actual source is supplied or made accessible through an authorized project channel:

- GPT-1 owns Source Verification once evidence is available.
- GPT-2 owns independent audit and the Phase 2.1 gate decision.
- The project source owner / data custodian owns obtaining or authorizing access to real source material.

No role may mark a source AVAILABLE solely because it is expected to exist.

## Phase 2.1 Opening Evidence

Phase 2.1 may open only when at least one candidate source has all required properties:

```text
REAL
+ ACCESSIBLE
+ CUSTOMER-ORIGINATED LANGUAGE PRESENT
+ TRACEABLE
+ PERMITTED FOR USE
```

For a source intended for Corpus use, the verification record must identify:

1. Exact source location or source identifier.
2. Source type.
3. Customer-origin status.
4. Direct vs reported status.
5. Provenance preservation method.
6. Applicable privacy/confidentiality boundary.
7. Whether the source is Corpus-eligible or Cross-check-only.

## Evidence Gap vs Reality Gap

Current status must be described as:

```text
EVIDENCE GAP / SOURCE VERIFICATION GAP
```

This means the current evidence does not establish an eligible source.
It must not be rewritten as:

```text
NO CUSTOMER LANGUAGE EXISTS
```

A Reality Gap may be recorded only after an explicitly bounded and adequate acquisition/search effort has been completed and documented.

## Acquisition Stop Rule

The project should not create an open-ended source hunt.

Acquisition stops for the current V1 decision when one of the following is true:

### Open
A real, traceable, permitted Customer Language Source is obtained and verified.

### V1 Gap
After the agreed source classes and available project channels have been explicitly checked, no eligible source can be obtained for V1.

### Not Authorized
A source may exist, but access/use is not permitted or its provenance/privacy boundary cannot be established.

In the latter two cases, Phase 2.1 remains blocked and the resulting gap is recorded explicitly.

## No Corpus Before Gate

Until the Phase 2.1 opening condition is satisfied:

- No Customer Language Corpus entries.
- No synthetic expressions presented as observations.
- No transformation into Problem, Need, Diagnosis, Product Fit, or Recommendation.
- No Domain Skeleton revision based merely on the absence of source evidence.
